# PlusOne

## The problem we're solving:

Imagine two friends watching a horror movie late at night on the same laptop or phone. They each have their own earphones, but the device can output audio to only one selected audio device at a time.

If they connect one pair of earphones, only one person can listen privately. If they use a single pair between them, they miss the comfort and immersive experience of using their own earphones. Connecting multiple Bluetooth devices or combining wired and wireless earphones is not consistently supported across devices and operating systems.

PlusOne aims to solve this by allowing multiple people to listen to the same media through their own audio devices, simultaneously and in sync, using one source device.
